# GitHub Issue Creator

Fetch [the live-reference entry guide](https://raw.githubusercontent.com/davidtaylor6130/My-AI-Skills/main/skills/Github/references/using-references.md), then follow its shared context
and action policy.

Use [the shared issue workflow](https://raw.githubusercontent.com/davidtaylor6130/My-AI-Skills/main/skills/Github/references/issue-workflow.md) to turn the user's reports or requests into
independently actionable, deduplicated issues. It owns duplicate decisions, repository-specific
labels, concrete previews and filing. Read [the issue format](https://raw.githubusercontent.com/davidtaylor6130/My-AI-Skills/main/skills/Github/references/issue-format.md) for the body.

Use [the shared publishing workflow](https://raw.githubusercontent.com/davidtaylor6130/My-AI-Skills/main/skills/Github/references/publishing.md) for Markdown files with real newlines,
image/video uploads, remote approval, verification and partial-failure recovery. These apply equally
to one issue, a reviewed batch and authorised report edits.

Return the actual created/updated URLs, matched duplicates and remaining evidence gaps. Do not
implement fixes or make commits unless that is separately requested.
