# GitHub action policy

Automatic skill selection never authorises an action.

## Interactive work

Ask before committing unless the user already requested a commit. Always ask before push, pull-request creation, merge, release, or destructive issue/branch operations.

## Goal or autonomous work

The goal may pre-authorise reversible local edits, tests, local branches, and tested local commits. Pushes, pull requests, releases, merges, destructive changes, tracker mutations, and external messages remain disallowed unless the goal explicitly grants that capability.

Read-only repository and GitHub inspection is allowed when needed. Keep credentials out of commands and artifacts. Report skipped actions rather than treating them as implied.
